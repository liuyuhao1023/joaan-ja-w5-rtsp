# 研究记录及证据边界

## 观察链条

- 对自有设备及局域网做端口检查，发现 RTSP 554 和本地 Web。
- APK（乔安智联 5.3.22.40）静态分析发现 RTSP 鉴权配置方法名及 SDK 线索，帮助确定优先验证本地协议。
- 本地 RTSP 返回 401 后继续验证设备合法凭据，最终用 FFmpeg / MediaMTX 独立获取实际视频，手机 App 不需要常开。
- 实际媒体轨道显示 H.265；本次录像机直连表现为码流不支持。未断言该型号录像机的所有通道/配置都不支持 H.265。
- ONVIF 编码修改没有改变本次样机的实际输出，改用 libx264 兼容转码。
- 最小 ONVIF 代理提供 H.264 profile 和 RTSP URI，成功使 NVR 通道在线且返回实际 JPEG 画面。
- 摄像头静态地址在实际重启后生效；修正中转旧源地址后恢复。
